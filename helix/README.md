# Helix

Helix 25.07 in the SilkCircuit glow theme, with the Space leader laid out like the AstroNvim config next door.
`~/.config/helix/config.toml` and `languages.toml` link here.

- `config.toml` holds editor options and the keymap. Motions stay stock Helix; the Space groups mirror Neovim.
- `languages.toml` wires the language servers and formatters, the same binaries the Neovim config installs through
  Mason. `sh/helix.sh` puts them on PATH.
- `~/.config/helix/themes/` is filled by the SilkCircuit installer and is not tracked here.

The full tour lives in `docs/helix/`.
